# 🐹 기니피그네이터 로컬 테스트 체크리스트

> SNS 공유 기능 제외. `npm run dev` 실행 후 `http://localhost:3000` 에서 진행.

---

## 1. 이미지 업로드

### 1-1. 클릭 업로드
- [ ] 드롭존 클릭 시 파일 선택 다이얼로그가 열린다
- [ ] JPG 파일 선택 → 크롭 모달이 열린다
- [ ] PNG 파일 선택 → 크롭 모달이 열린다
- [ ] WebP 파일 선택 → 크롭 모달이 열린다

### 1-2. 드래그앤드롭
- [ ] 파일을 드롭존 위로 드래그 시 테두리/배경이 amber 색으로 바뀐다
- [ ] 파일을 드롭존 밖으로 벗어나면 원래 스타일로 돌아온다
- [ ] JPG 파일 드롭 → 크롭 모달이 열린다

### 1-3. 파일 유효성 검사
- [ ] GIF, BMP, PDF 등 비허용 형식 업로드 시 Toast 에러 메시지 출력 ("JPG, PNG, WebP 형식만 허용")
- [ ] 10MB 초과 파일 업로드 시 Toast 에러 메시지 출력 ("10MB 이하여야 합니다")
- [ ] 유효성 실패 시 크롭 모달이 열리지 않는다

---

## 2. 이미지 크롭

### 2-1. 기본 동작
- [ ] 업로드 직후 크롭 모달이 자동으로 열린다
- [ ] 이미지가 모달 안에 표시된다
- [ ] 기본 크롭 영역(80%)이 미리 선택되어 있다

### 2-2. 크롭 조작
- [ ] 크롭 영역을 드래그로 이동할 수 있다
- [ ] 크롭 영역 모서리를 드래그하여 크기를 조절할 수 있다
- [ ] 최소 크기(50×50px) 이하로 줄어들지 않는다

### 2-3. 크롭 완료 / 취소
- [ ] "크롭 완료" 클릭 → 모달이 닫히고 크롭된 이미지 미리보기가 표시된다
- [ ] "취소" 클릭 → 모달이 닫히고 업로드 드롭존으로 돌아온다

---

## 3. 이미지 미리보기

- [ ] 크롭 완료 후 미리보기 이미지가 표시된다
- [ ] "크롭 수정" 버튼 클릭 → 크롭 모달이 다시 열린다
- [ ] "다시 선택" 버튼 클릭 → 초기 드롭존 화면으로 리셋된다
- [ ] 리셋 후 다른 이미지를 새로 업로드할 수 있다

---

## 4. 기니피그 변환 (Mock)

### 4-1. 변환 시작
- [ ] 미리보기 화면에서 "🐹 기니피그로 변환하기" 버튼이 보인다
- [ ] 버튼 클릭 시 변환 로딩 화면(ConvertingLoader)으로 전환된다
- [ ] 전환 시 fade-in 애니메이션이 적용된다

### 4-2. 변환 로딩 UI
- [ ] 🐹 이모지가 bounce 애니메이션으로 표시된다
- [ ] 프로그레스 바가 점진적으로 증가한다 (90%에서 멈춤)
- [ ] 단계별 메시지가 순서대로 바뀐다 ("기니피그 DNA 분석 중..." → ... → "기니피그 완성 중...")

### 4-3. 변환 완료
- [ ] 약 2초 후 결과 화면으로 자동 전환된다
- [ ] 전환 시 fade-in 애니메이션이 적용된다

---

## 5. 변환 결과 화면

- [ ] "Before" 영역에 원본(크롭된) 이미지가 표시된다
- [ ] "After 🐹" 영역에 변환 결과 이미지(placeholder)가 표시된다
- [ ] "⬇️ 이미지 저장" 버튼 클릭 시 이미지가 `guinea-pig-me.png` 파일명으로 다운로드된다
- [ ] "다시 변환하기" 버튼 클릭 시 초기 드롭존 화면으로 돌아간다

---

## 6. 에러 처리

### 6-1. Rate Limit (분당 3회 초과)
- [ ] 1분 내에 변환을 4회 시도하면 429 응답이 온다
- [ ] Toast 에러 메시지가 출력된다 ("요청 횟수를 초과했습니다")
- [ ] 에러 UI (😢)로 전환된다
- [ ] "다시 시도하기" 버튼 클릭 시 초기 화면으로 돌아간다

### 6-2. Toast
- [ ] 에러 Toast가 화면 하단에 표시된다
- [ ] 일정 시간 후 Toast가 자동으로 사라진다

---

## 7. 전체 플로우

- [ ] 업로드 → 크롭 → 미리보기 → 변환 → 결과 → 다시 변환하기 전 과정이 끊기지 않고 동작한다
- [ ] 각 단계에서 뒤로 가기(리셋/취소)가 정상 동작한다
- [ ] 모바일 뷰(375px)에서 레이아웃이 깨지지 않는다
- [ ] 데스크톱 뷰(1280px)에서 레이아웃이 깨지지 않는다
